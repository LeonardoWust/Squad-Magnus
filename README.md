# Squad Magnus

Landing page para apresentar a consultoria de treinamento do Fagner Magnus a pessoas interessadas em acompanhamento físico. O site reúne informações sobre o treinador, a metodologia e os resultados apresentados.

- Lucide React

## Como rodar

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
